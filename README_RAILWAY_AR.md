# تشغيل Egypt Melook على Railway

هذا المجلد يحتوي على العامل الذي ينشر العروض وصور الشاشة. خدمة اختصار الروابط الحالية تبقى كما هي على Railway؛ العامل يتصل بها عبر EGYPT_SHORT_BASE_URL و EGYPT_SHORT_API_KEY. **لا تغيّري قاعدة بيانات خدمة الاختصار القديمة أو الدومين**؛ الروابط المنشورة تعتمد عليهما.

1. ارفعي محتويات هذا المجلد إلى مستودع GitHub خاص. اختاريه في Railway كـ **خدمة جديدة مستقلة** عن خدمة الاختصار، واجعلي Root Directory يشير إلى هذا المجلد إذا وضعتِه داخل مستودع أكبر. Railway سيستخدم Dockerfile، وStart Command هو القيمة الموجودة فيه.
2. على جهازك فقط، شغلي `pip install telethon` ثم `python create_session.py` وأدخلي كود Telegram وكلمة مرور التحقق الثنائي إن طُلبت. انسخي قيمة TELEGRAM_SESSION إلى متغير سري في خدمة العامل؛ لا تضعيها في GitHub ولا ترسليها لأي شخص. لا تشغلي الجلسة نفسها على جهازك والعامل في وقت واحد.
3. أضيفي المتغيرات الآتية في خدمة العامل: `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_SESSION`, `AMAZON_CLIENT_ID`, `AMAZON_CLIENT_SECRET`, `EGYPT_SHORT_BASE_URL`, `EGYPT_SHORT_API_KEY`. استخدمي القيم الموجودة في تشغيلك الحالي وخدمة الاختصار. لا تضعي علامة اقتباس حول القيم.
4. أضيفي Railway Volume عند `/data` واضبطي `STATE_DIR=/data` للاحتفاظ بسجل العروض المرسلة واختيارات القنوات بعد إعادة التشغيل. قبل التشغيل الأول، إذا كانت اختيارات القنوات على جهازك مهمة، انسخي `forwarder_startup_settings.json` إلى الـvolume. عند غياب الملف سيبدأ بجميع المصادر المعروفة مع تعطيل نقل Hunter إلى Melook؛ لا توجد أسئلة تفاعلية على Railway.
5. اختبري الـDeploy: ينبغي ظهور `سكرين شوت ... (شغّال)` و`البوت متصل وشغّال`. Dockerfile يتضمن Chromium وPlaywright وخطوط العربية؛ كل محاولات تصوير Playwright تتم Headless. جرّبي بوست اختبار ثم تأكدي من صورة الشاشة والرابط المختصر في القناة.
6. بعد التأكد من نجاح الاختبار، أوقفي نسخة الكمبيوتر لتجنب إرسال نفس العرض مرتين. اجعلي عدد Replicas للخدمة **واحدًا**.

إذا ظهر `Missing Railway variables` فالمتغير الناقص مذكور في رسالة الخطأ. إذا كان Amazon يمنع تصفح صفحات المنتجات من عنوان Railway فقد تفشل بعض صور الشاشة، حتى لو نجح تشغيل Chromium؛ راجعي الـlogs والبوست التجريبي. صورة المنتج الأصلية في المسارات التي تدعمها الشفرة هي الحل الاحتياطي الموجود أصلًا.
